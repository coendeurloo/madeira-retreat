# Материалы ретрита «Без масок»

Заменяйте временные изображения в компонентах на реальные материалы, не меняя имена категорий:

- `hero/` — отдельный мобильный кроп первого экрана, если потребуется;
- `atmosphere/` — минимум пять фотографий прошлого ретрита;
- `final-shoot/` — фото Achadas da Cruz; `achadas-da-cruz-golden-hour.jpeg` уже используется в блоке финальной съёмки;
- `villa/` — только фотографии забронированной виллы;
- `team/` — оригинальные фотографии Элии и Оли;
- `testimonials/` — обложки видеоотзывов и ссылки Vimeo/YouTube.

До добавления реальных материалов сайт показывает только явно обозначенные временные визуальные блоки.
